\doxysubsection{Detailed Description}
Base interface for the \doxylink{class_command}{Command} pattern used to handle incoming packets. 


\begin{DoxyItemize}
\item Every specific action (like logging in, joining a room, or sending a message) inherits from this class and implements its own execute method. 
\end{DoxyItemize}
