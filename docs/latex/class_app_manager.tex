\doxysubsection{Detailed Description}
Class responsible for client side connection between all app segments while keeping them separate. 


\begin{DoxyItemize}
\item It acts as the core orchestrator (controller) of the client application, managing the lifecycle of user interface windows and binding business logic from network and audio systems together. 
\end{DoxyItemize}
