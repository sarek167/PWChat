\doxysubsection{Detailed Description}
The main graphical user interface class of the client application. 


\begin{DoxyItemize}
\item This class handles all user interactions, visual component rendering, layout updates, and bridges the user interface layer with the underlying network and media systems through Qt signals and slots. 
\end{DoxyItemize}
