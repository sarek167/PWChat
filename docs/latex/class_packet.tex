\doxysubsection{Detailed Description}
Class representing a full network packet that holds both a header and data (body). 


\begin{DoxyItemize}
\item It uses the Cereal library to easily change structures/\+objects into raw bytes ready to send over the network, and vice versa. 
\end{DoxyItemize}
