\doxysubsection{Detailed Description}
\doxylink{class_command}{Command} handler used when a client requests to load chat history. 


\begin{DoxyItemize}
\item It inherits from the base \doxylink{class_command}{Command} class and overrides the execute method to handle fetching archived messages for both rooms and private conversations.
