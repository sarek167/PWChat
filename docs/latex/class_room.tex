\doxysubsection{Detailed Description}
Base class representing a general chat room on the server. 


\begin{DoxyItemize}
\item It manages the list of connected clients, chat room details, and administrators. This class is abstract, meaning specific room types (like Public or Private) must inherit from it. 
\end{DoxyItemize}
