\doxysubsection{Detailed Description}
Data transfer object (DTO) struct used for requesting to join an existing chat room. 


\begin{DoxyItemize}
\item It carries the name of the target room channel and an optional invitation passcode token required to pass the security verification challenge for private spaces. 
\end{DoxyItemize}
