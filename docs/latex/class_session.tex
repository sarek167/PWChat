\doxysubsection{Detailed Description}
Represents a single active client connection on the server. 


\begin{DoxyItemize}
\item This class inherits from std::\+enable\+\_\+shared\+\_\+from\+\_\+this so we can safely pass shared pointers of this session to rooms or async Asio handlers. It reads data from the socket, authenticates the user, and sends packets back. 
\end{DoxyItemize}
