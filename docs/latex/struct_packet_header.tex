\doxysubsection{Detailed Description}
Fixed-\/size header placed at the beginning of every network packet. 


\begin{DoxyItemize}
\item It uses 1-\/byte alignment to make sure the structure looks exactly the same in memory on both the client and the server when sending data over sockets. 
\end{DoxyItemize}
